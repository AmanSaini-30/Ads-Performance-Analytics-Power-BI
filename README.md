 # 📊 Ads Performance Analytics Dashboard | Power BI

An interactive Power BI dashboard designed to analyze Facebook and Instagram advertising performance, engagement, clicks, impressions, conversions, and campaign-related KPIs.

---

## 📌 Project Overview

This project focuses on analyzing digital advertising data and converting it into meaningful business insights using Microsoft Power BI.

The dashboard provides an interactive view of advertising performance and allows users to explore trends, engagement, clicks, conversions, and campaign performance through KPI cards, charts, tables, filters, and slicers.

---

## 🎯 Business Objective

The main objective of this project is to:

- Monitor advertising performance using key KPIs
- Analyze Facebook and Instagram campaign performance
- Understand user engagement and click activity
- Analyze impressions, CTR, and conversions
- Identify trends and performance patterns
- Support data-driven marketing decisions

---

## 📈 Key KPIs & Metrics

The dashboard analyzes important advertising metrics such as:

- Click-Through Rate (CTR)
- Conversions
- Engagement
- Shares
- Comments
- Purchases / Conversion Events
- Reach

2. Data cleaning

6. KPI development

8. Data validation
9. Business insight generation
